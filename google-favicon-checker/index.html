Google Favicon Checker

Use this simple bookmarklet on any website to check if Google has indexed its favicon. It fetches the cached favicon directly from Google, making it an easy way to verify whether the favicon is accessible and indexed by Google.


Google Favicon Checker

Installation Instructions:

Drag the button above to your bookmarks bar. If you don't see the bookmarks bar, enable it in your browser settings.

How To Use:

  • To check a site's favicon, run the bookmarklet on the site.
  • It will show you the favicon as cached by Google, if it's been indexed.
