Trello Filter Exclude Label

Trello's built-in filtering has a limitation: you can only include labels, not exclude them. This can be frustrating when you want to hide cards with specific labels. Our bookmarklet solves this problem by allowing you to quickly exclude cards based on label colors. It's a simple yet powerful tool that enhances Trello's filtering capabilities, making it easier to focus on the cards that matter most to you.


Trello Filter Exclude Label

Installation Instructions:

Drag the button above to your bookmarks bar. If you don't see the bookmarks bar, you might need to enable it in your browser settings.

How To Use:

  • When you are on a Trello Board, run the bookmarklet.
  • A popup should appear that allows you to select a list of labels based on the color used. Select the ones you want to exclude. You can choose multiple ones to exlude.
  • Click on Submit.
  • Trello Cards with those labels should now be hidden from view.

Some Limitations:

  • The bookmarklet can't differentiate labels with different names, everything with the same color will be hidden.
