Webpage to Markdown Bookmarklet

Drowning in cluttered webpages? What if you could instantly turn any article into a clean, distraction-free MARKDOWN summary with just one click? This webpage to markdown bookmarklet transforms any URL into a neat, reader-friendly version instantly, in a new tab, using Jina Reader's AI engine.

Webpage to Markdown v1.0

Tip - if the button will not drag, right click it and choose Bookmark link.

How it works?

  • Detects a URL in this order:
    • highlighted text that looks like a URL
    • the href of the focused link
    • the current tab’s URL
  • Encodes the URL.
  • Opens the Jina Reader version in a new tab.

Limitations: If you select text that has multiple URLs, it will only pick the first URL and run it through jina.ai.

Bugs: Let me know and I will sort them out.

Why use the bookmarklet to convert a Webpage to Markdown?

This is a quick way to convert any webpage into LLM-friendly content, so you can easily copy-paste into LLMs.

  • ✓Saves you time.
  • ✓Get LLM-friendly content easily.

Features of Webpage to Markdown

An easy-to-use bookmarklet that gets you what you need in one click and should work for all modern browsers.

Feature 1
Works on the current page by default.
Feature 2
If you highlight a URL on the page, it’ll use that instead.
